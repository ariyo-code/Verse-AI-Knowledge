# UEFN MCP — Live Editor Bridge

Le dépôt est la mémoire longue durée de l'agent. UEFN MCP est sa connexion au vrai éditeur.

```text
Verse-AI-Knowledge
    ↓ retrieval
AI coding agent
    ↓ MCP
UEFN
    ├─ lit / écrit Verse
    ├─ compile Verse
    ├─ place / configure des devices
    ├─ manipule Scene Graph
    ├─ lance une session
    └─ inspecte les logs
```
