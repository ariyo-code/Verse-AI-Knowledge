# Verification Evidence

Ce dossier stocke les preuves qui permettent de promouvoir du code :

```text
draft → compiled → verified → multiplayer-verified
```

## `compiled`

Exige :
- compilation UEFN réussie.

## `verified`

Exige :
- compilation réussie ;
- comportement testé.

## `multiplayer-verified`

Exige :
- compilation ;
- test runtime ;
- test multijoueur pertinent.

Ne jamais promouvoir un exemple uniquement sur la confiance de l'IA.
