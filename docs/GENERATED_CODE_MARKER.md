# Generated-Code Marker — V22

Verse AI Knowledge uses a normal Markdown HTML comment for generated-code provenance.

```html
<!-- verse-ai-generated:v22;lang=verse;status=draft -->
```

Allowed local validation statuses are:

`draft`, `static-checked`, `compiled`, `verified`, `multiplayer-verified`.

Do not put source-trust labels such as `api-page-verified` into the `status` field.

Do not use zero-width characters, bidirectional controls, invisible Unicode tags, or altered identifiers as hidden markers.

Never claim `compiled`, `verified`, or `multiplayer-verified` without real corresponding evidence.
