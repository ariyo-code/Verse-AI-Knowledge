# Generated Verse provenance — V25

Generated Verse in Markdown uses two complementary surfaces:

1. a **visible validation block** for humans;
2. a **machine-readable provenance comment** using a normal HTML comment.

Example:

```markdown
> **Verse AI Knowledge · V25**
> Status: `draft` · API snapshot: `42.20` · UEFN compile: `NOT TESTED` · Runtime: `NOT TESTED` · Multiplayer: `NOT TESTED`

```verse
# generated Verse
```

<!-- verse-ai-provenance:v25;lang=verse;artifact=VAI-...;knowledge_release=25.0.0;api=42.20;status=draft;compiled=false;runtime=false;multiplayer=false;api_verify_required=false;uncertain_api_count=0;claim_resolution=field-level -->
```

No zero-width, bidi-control, Unicode-tag or other hidden Unicode mechanism is allowed.

`compiled`, `verified` and `multiplayer-verified` require matching real evidence. Static checks never promote an artifact to UEFN-compiled.
