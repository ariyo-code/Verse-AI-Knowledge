# VerseLab

VerseLab is the repository workflow for recording real UEFN compile/runtime evidence without promoting candidates by confidence alone.

See the repository files `lab/RUNNER.md`, `lab/ONE_CLICK_GUIDE.md`, and `lab/SELF_HOSTED_UEFN.md` for the operational workflow.

A candidate must never jump directly from pending/staged to verified. Compilation, runtime, and multiplayer promotions require their corresponding evidence.
