# CLI

The `verse-ai` command is the main automation surface.

```bash
verse-ai version
verse-ai doctor
verse-ai search "vehicle ownership" --json
verse-ai api GetFortCharacter --json
verse-ai claim GetFortCharacter --field signature --json
verse-ai explain GetFortCharacter --json
verse-ai evidence GetFortCharacter --json
verse-ai coverage --json
verse-ai api-queue --json
verse-ai lint path/to/file.verse
verse-ai status --json
verse-ai validate
```
