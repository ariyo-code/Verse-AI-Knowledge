# `fort_playspace`

**Statut :** official-current

**Vérification :** catalog

**Module :** `/Fortnite.com/Playspaces`

Conteneur du gameplay courant donnant accès aux joueurs, participants et équipes.

## Membres

- `GetPlayers`
- `GetTeamCollection`
- `PlayerAddedEvent`
- `PlayerRemovedEvent`
- `GetParticipants`
- `ParticipantAddedEvent`
- `ParticipantRemovedEvent`

## Attention

- GetPlayers renvoie les joueurs humains ; GetParticipants inclut aussi des agents participants non humains.
