# `hud_message_device`

**Statut :** official-current

**Vérification :** catalog

**Module :** `/Fortnite.com/Devices`

Affiche des messages HUD personnalisés à un ou plusieurs agents.

## Événements

- `ClearAllMessagesEvent`
- `HideMessageEvent`
- `ShowMessageEvent`

## Membres

- `Show`
- `Hide`
- `ClearAllMessages`
- `SetText`
- `SetDisplayTime`
- `GetDisplayTime`

## Attention

- SetText limite le texte à 150 caractères d'après la référence actuelle.
