# `creative_device`

**Statut :** official-current

**Vérification :** catalog

**Module :** `/Fortnite.com/Devices`

Base à hériter pour créer un device Verse personnalisé dans UEFN.

## Membres

- `OnBegin`
- `OnEnd`
- `GetTransform`
- `TeleportTo`

## Attention

- Les coroutines lancées dans OnEnd peuvent ne jamais s'exécuter.
