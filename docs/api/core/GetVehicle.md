# `GetVehicle`

**Statut :** official-current

**Vérification :** signature-verified

**Module :** `/Fortnite.com/Vehicles`

Retourne le fort_vehicle associé à un fort_character; échoue s'il n'y en a pas.

## Signature

```verse
(InCharacter:fort_character).GetVehicle<public><native>()<transacts><decides>:fort_vehicle
```

## Effets

- `<transacts>`
- `<decides>`
