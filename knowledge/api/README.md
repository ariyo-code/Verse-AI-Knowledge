# Structured Verse API Knowledge

V22 introduces a progressive symbol index generated from the legacy catalog.

- `symbols.jsonl` — one structured symbol record per line.
- `modules.json` — module snapshot derived from `knowledge/module_catalog.json`.
- `versions.json` — known repository API snapshot metadata.

These files are generated by `tools/migrate_api_catalog_v22.py` / `tools/upgrade_v22.py`.

A missing signature remains missing. A legacy signature without classified signature evidence is preserved but cannot be emitted as an exact verified claim.
