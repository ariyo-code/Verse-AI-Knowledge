# Opaque project patterns

These files are recognition fingerprints, not project profiles.

They contain only:
- opaque IDs;
- salted hashes;
- coarse structural fingerprints;
- generic safe-assistance rules.

They do **not** contain:
- real project names;
- private source code;
- server/community names;
- a mapping from an opaque ID to a real project.

The public repository intentionally cannot reveal the real project identity.
