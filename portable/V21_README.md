# Verse AI Portable v21

V21 = Verse AI Portable v20 + **UI Creator**.

Use either:

- `VERSE_AI_MASTER_PROMPT_v21_WITH_UI.txt` for the full Verse + UI brain.
- `ui_creator/VERSE_UI_CREATOR_MASTER_PROMPT.txt` if you only want UI generation.

The UI Creator supports prompt-to-UI, image-to-UI planning, redesign, components, event binding and responsive refactoring.
