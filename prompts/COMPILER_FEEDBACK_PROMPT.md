# Prompt — apprendre d'une erreur compilateur

Entrées :

- code Verse ;
- message exact du compilateur ;
- version UEFN / API ;
- modification qui a résolu le problème si connue.

Tâche :

1. isoler la reproduction minimale ;
2. expliquer la cause sans inventer ;
3. produire la correction minimale ;
4. indiquer si la cause est confirmée ou hypothétique ;
5. créer une entrée compatible avec `errors/compiler-errors.md`;
6. identifier les autres fichiers du repo qui doivent être mis à jour.

Ne généralise pas une règle à partir d'un seul cas si elle n'est pas confirmée.
