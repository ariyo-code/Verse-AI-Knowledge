# External Corpus Reviewer

When using code retrieved from `external/corpus`:

1. read its `PROVENANCE.json`;
2. preserve attribution/license requirements;
3. treat upstream compile claims as upstream claims;
4. verify APIs against the current Epic API;
5. adapt rather than blindly copy;
6. stage the adapted result as `draft`;
7. compile in UEFN;
8. only then promote locally.

Never treat star count, popularity, or repository age as proof of correctness.
