# B009-error-learning — Learn from compiler feedback

Level: `compile`

## Goal

À partir d'un vrai message UEFN, rechercher mémoire, corriger, recompiler et enregistrer la preuve.

## Required concepts

- `error memory`
- `exact message`
- `compile evidence`

## Must consider

- same message may have different causes

## Forbidden

- fabricated compiler message
- marking fixed before compile

## Verification

- error-memory-entry
- uefn-compile
