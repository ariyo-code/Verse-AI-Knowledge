# Real Project Bridge

V11 relie la base de connaissances à un vrai projet UEFN.

## Objectif

```text
Ton projet UEFN
      ↓
scan Verse
      ↓
profil projet réel
      ↓
RAG context
      ↓
Codex
      ↓
UEFN MCP
      ↓
compile
      ↓
erreurs réelles
      ↓
error memory
      ↓
recompile / playtest
```

## Important

Le bridge ne remplace jamais ton projet.

Il lit, indexe et prépare le contexte.

Les modifications réelles restent dans le projet UEFN et doivent être compilées/testées.
